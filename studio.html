🎙️ Xưởng giọng Trâu Con

Tạo giọng đọc "Elio" (Google AI Studio) cho toàn bộ trang Khám phá Việt Nam. Trang này chỉ dành cho người quản lý, không có đường dẫn trên trang học.

1. Cài đặt

2. Tạo giọng

Tổng: 0 câuĐã có: 0Còn lại: 0
Chưa chạy. Dán mã API rồi bấm "Bắt đầu".

3. Tải gói giọng và đưa lên GitHub

Bấm nút dưới đây bất cứ lúc nào (không cần đợi xong hết). Gói tải về gồm thư mục audio (mỗi trạm một file) và file js/audio-manifest.js.

  1. Giải nén file zip vừa tải.
  2. Trên GitHub, mở repo của trang Khám phá Việt Nam → Add file → Upload files.
  3. Kéo cả thư mục audio và thư mục js (chỉ có file audio-manifest.js) vào, rồi bấm Commit changes. File cũ cùng tên sẽ được thay.
  4. Khoảng 1–2 phút sau, mở lại trang: Trâu Con sẽ nói bằng giọng Elio. Câu nào chưa tạo vẫn đọc bằng giọng máy.

4. Danh sách câu

CâuTrạm

Khi bạn sửa chữ trong js/stops.js, câu đã sửa sẽ hiện là "chưa có" để tạo lại; các câu khác giữ nguyên.
